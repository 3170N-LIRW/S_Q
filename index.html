Asher & Eliezer — Password and Message Utility

A browser utility inspired by my twin sons, Asher and Eliezer.

Uses browser cryptography to generate passwords and encrypt text. This project has not been independently audited and is not a complete secure messaging service. A compromised page, browser, extension or device can expose your secrets.

Encrypt or decrypt text locally

Generate a random key or paste a previously generated key. Passphrases are not accepted. Save the key separately from the encrypted text, and share it only through a trusted separate channel. Replacing or losing a key can make existing messages unrecoverable.

Plaintext limit: 65,536 UTF-8 bytes. Older CryptoJS messages are incompatible.

Generate a password

Include at least one character from each selected type

Longer, unique passwords are preferable. This utility does not store passwords.

Clearing fields is not secure memory erasure. Copies may remain in clipboard history, screenshots or browser memory. See README.md for the format, limitations and deployment requirements.
